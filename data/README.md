# Datos locales

Los directorios `raw/`, `interim/`, `processed/` y `cache/` contienen datos generados/locales e ignorados por Git. El pipeline inicial usa la fuente registrada en `../configs/sources.json`; el corpus, sus manifiestos y las métricas quedan fuera del control de versiones. Véase `../docs/data-pipeline.md` para decisiones, límites y resultados.
